🐍 Python Learning Posters

Learn Python one concept at a time!

1. Introduction to Python

Python is a programming language used to build apps, websites, and more.

print("Hello, World!")

💡 Remember: print() displays output.

2. Variables

Variables store information.

name = "Alex"
age = 18

print(name)
print(age)

💡 Use = to assign a value to a variable.

3. Data Types

Python supports different kinds of data.

name = "Sam"       # String
age = 20           # Integer
price = 9.99       # Float
is_ready = True    # Boolean

💡 Strings store text; integers store whole numbers.

4. Input and Output

Take information from the user and display a response.

name = input("Your name: ")
print("Hello,", name)

💡 input() receives text from the user.

5. If-Else Conditions

Make decisions based on conditions.

age = 18

if age >= 18:
    print("Adult")
else:
    print("Minor")

💡 Python uses indentation to group code.

6. Loops

Repeat instructions using a loop.

for i in range(1, 6):
    print(i)

💡 This example prints numbers 1 through 5.

7. Functions

Functions let you reuse blocks of code.

def greet(name):
    print("Hello,", name)

greet("Alex")

💡 def is used to define a function.

8. Lists

Lists store multiple items in one variable.

fruits = ["apple", "mango", "banana"]

print(fruits[0])
fruits.append("orange")

💡 List indexing starts at 0.
